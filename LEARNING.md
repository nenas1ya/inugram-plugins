# Конспект по TypeScript

Пополняется по мере работы над плагинами. Примеры взяты из кода этого репо.

## 0. Что такое TypeScript

TypeScript — это JavaScript с аннотациями типов. При сборке (`pnpm build`) типы стираются,
и остаётся обычный JS, который выполняет движок QuickJS внутри Inugram. Типы нужны только
для проверки (`pnpm check`) и подсказок в редакторе.

```ts
function greet(user: { name: string }) {
  return 'привет, ' + user.nmae
  //                       ^^^^ ошибка ещё до запуска: такого поля нет
}
```

## 1. Переменные: `const` и `let`

- `const x = 1` нельзя переприсвоить. Используем по умолчанию.
- `let x = 1` можно потом написать `x = 2`.
- `var` устарел, не используем.

## 2. Типы в функциях

```ts
function readFlag(key: string, fallback: boolean): boolean { ... }
//                     ^^^^^^ тип аргумента       ^^^^^^^ тип результата
```

Базовые типы: `string`, `number` (любые числа, отдельного int нет), `boolean`, `null`, `undefined`.
`void` значит «ничего не возвращает». `string | null` значит «строка или null»: это union-тип.

Часто типы писать не нужно, TS выводит их сам (type inference). Например, у `onChange: (checked) => ...`
он знает, что `checked` — это boolean.

## 3. Стрелочные функции

```ts
const double = (x: number) => x * 2         // короткая форма: сразу возвращает значение
const log = (x: number) => { console.log(x) } // с телом в {}: return нужно писать самому
```

## 4. Объекты и массивы

```ts
const opts = { title: 'Hello', count: 3 }  // объект: ключ → значение
opts.title                                 // 'Hello'
const list = ['a', 'b']                    // массив
list[0]                                    // 'a'
```

## 5. Модули: `import` / `export`

`export function f` в одном файле → `import { f } from './file.js'` в другом.
Расширение пишем `.js`, даже если файл `.ts`.

## 6. Сравнение и тернарник

- Всегда `===` и `!==`, никогда `==`.
- `cond ? a : b` — if/else, который возвращает значение.

## Команды проекта

| Команда | Что делает |
| --- | --- |
| `pnpm check` | проверяет типы, манифесты и разрешения |
| `pnpm build` | собирает `dist/<плагин>.inu.js` |
| `pnpm dev <плагин>` | заливает плагин на телефон по adb и перезагружает его при каждом сохранении |
